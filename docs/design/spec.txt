Brand 
The mark is a ruled 3×3 box with pencil marks in place. The candidates 1 3 4 5 6 7 9 sit in their fixed slots and spell an H. The 5 in the centre is accent blue — the one you're about to place. The grid lines are what make it read as sudoku, not dice.

 MARK · SIZES 
 CONSTRUCTION A square box ruled into a 3×3 grid. The outer rule is about 3× the inner rules, the way box lines are drawn on the board. Digits are Plex Mono 600 at 20% of the mark's width. Corner radius is 6%. 
 CLEAR SPACE Keep one cell-width of space on every side. Don't place the mark inside another box. 
 BELOW 24PX Under 60px the digits become small square marks in the same slots. Under 24px use the filled favicon: inverted, with rules kept. 
 WORDMARK “Hodoku” in Newsreader 500. “Revisited” in Plex Mono, uppercase, tracked +0.42em, set at about 24% of the cap height.

 Techniques / Intersections 
Locked Candidates 
 Medium 
 Type 1 · Pointing 
 Type 2 · Claiming 
A box and a row (or column) overlap in three cells. If a digit can only go in that overlap for one of them, it can't go anywhere else in the other. 
Type 1 · Pointing 
In box 3 the digit 4 only fits in r1c7 and r1c9, both in row 1. Wherever the 4 goes in box 3, it uses up row 1. So the 4 at r1c6 can be eliminated. 
 NOTATION 
 Locked Candidates Type 1 (Pointing): 4 in b3 ⇒ r1c6<>4 
Type 2 · Claiming 
This is the same overlap read the other way round. If a row's candidates for a digit all sit in one box, you can eliminate that digit from the rest of the box…

Hints 
A hint is the next step the solver would take from your current position. It names the technique, highlights the cells involved, strikes out what it removes, and links to the guide. “Hints use” limits which techniques it may use. 
 PART COMES FROM FIELD 
 What to do “remove 4 from r1c6” text 
 Why One-sentence reason summary 
 Chain AIC notation, for chain steps notation[] 
Tip: set “Hints use” to Singles only while you're learning. If nothing is found at that level, the hint suggests raising it.

 04 
Solver app 
The board gets the most space. App.tsx today is a 520px column with rows of buttons. Desktop gets a slim top bar, a digit row and a side panel with three tabs: Hint, All steps and Summary. Every existing control has a place. Use the Tweaks panel to toggle the hint and the digit filter.

 Apply 
 Breakpoints. Under 960px the side panel turns into a bottom sheet with three snap points: peek, half and full. Under 600px the top bar collapses to a menu, the difficulty badge and undo. 
 Board. The board is full width minus 20px. At 346px each cell is about 38px, so candidates are 9px Mono. That's the floor: on narrower screens candidate text stays at 9px and the cell padding shrinks instead. 
 Digit keys. One row of nine, each 56px tall, so the full key is tappable. Long-press a key to filter that digit. Swipe the sheet up to see All steps and Summary as tabs. 
 Dark mode. It follows prefers-color-scheme, as styles.css does now. A manual override in Settings is new. The board keeps its warm-ink character: givens are #ECE8DF, user digits are #9DB4F5.

 Layer order from bottom to top: card → tint a/b → filter → peer → same → hint-place → selected → candidate marks (.keyc / .fin / .del / col-0/1) → value. Eliminated candidates keep the strike-through they have today. Each candidate has a fixed slot in a 3×3 grid (1 is top-left, 9 is bottom-right), so a digit is always in the same place.

 HIGHLIGHT MODEL 
 Nothing changes in core. describeStep() already returns StepMarks { key, fins, elim, place, colors, tint, chains, digits }, and Board.tsx maps them to classes: key → .keyc, fins → .fin, elim → .del, place → .keep/.hint-place, colors → col-0/1, tint → tint-a/b, and chains → SVG lines (strong solid, weak dashed). The website diagrams use the same data, so restyle both from the same tokens. 
 ACCESSIBILITY · MOTION 
 Keep role="grid", the arrow keys and the aria-live status, which are already in place. Extend each cell's aria-label to read its candidates too (“row 1 column 6, candidates 3 4 5”). Animate only opacity and colour, for 120ms. Applying a step fades eliminated candidates over 200ms. Respect prefers-reduced-motion.
