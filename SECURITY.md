# Security policy

Hodoku Revisited runs entirely in the browser; it has no accounts and no server of its own. The things worth
reporting are a flaw in the site or app code, the build and deploy workflows, or a dependency.

Please report a problem **privately** through GitHub: open the repository's **Security** tab and choose
*Report a vulnerability*. Please do not open a public issue for it.

You can expect an answer within a few days. Only the latest version, the one deployed from `main`, is supported.
